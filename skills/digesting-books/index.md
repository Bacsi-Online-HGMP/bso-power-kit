# Documents

* [digesting-books](SKILL.md) - `Skill` — Use when a book, textbook, guideline, thesis, long report or other long PDF, EPUB or DOCX has to be read and kept as reusable notes, or when the user asks to digest, ingest, load or take notes on a book or reference material. Also use it for every question about a source digested earlier ("from my ... digest", "in my notes on ...") and whenever later work needs a long source whose notes are under `digests/notes/`.
